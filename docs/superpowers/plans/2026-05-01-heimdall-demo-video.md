# Heimdall Demo Video Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a 2-3 minute HyperFrames demo/showcase video for Heimdall and render the final MP4 to `/Users/modestnerd/Desktop/heimdall-demo-showcase.mp4`.

**Architecture:** Create a self-contained HyperFrames project in `demo-video/` that owns the visual identity, script, caption timing, capture assets, and composition source. The Heimdall app source remains unchanged; real UI credibility comes from running the local app with a seeded demo workspace and capturing key screens. The composition uses one root 1920x1080 HTML timeline with timed scene clips, transition overlays, synced narration, burned-in captions, and captured UI framed inside motion graphics.

**Tech Stack:** HyperFrames CLI via `npx hyperframes`, HTML/CSS, GSAP, local Heimdall Rust web app, PostgreSQL seed SQL, browser screenshots, FFmpeg/ffprobe.

- [ ] **Step 1: Write the HyperFrames visual identity file**

Create `demo-video/DESIGN.md` with this content:

```markdown
# Heimdall Demo Video Design

## Style Prompt

Developer-forward security product film with a serious security spine. The video feels like a practical launch demo rather than a theatrical trailer: fast enough for developers, restrained enough for security evaluators, and grounded in real product evidence. The visual language follows Heimdall's Oatmeal theme: dark mist canvas, raised panels, pale typography, quiet status colors, and precise motion.

## Colors

- Background: `#090b0c`
- Surface: `#191f22`
- Raised surface: `#20272a`
- Primary text: `#dde3e6`
- Muted text: `#7d8f95`
- Accent pill: `#d5dbde`
- Validated green: `#afc8af`
- Running amber: `#cab78f`
- Critical red: `#dfb0a6`

## Typography

- Product and UI text: Familjen Grotesk, Avenir Next, Segoe UI, sans-serif.
- Optional opening display: Georgia or Iowan Old Style fallback for one large title moment only.
- Data labels use tabular numbers and uppercase letterspacing.

## Motion

- Precise developer-tool pacing, not chaotic.
- Scene entrances start 0.1-0.3 seconds after a scene begins.
- Use GSAP `power3.out`, `expo.out`, `sine.inOut`, and `back.out(1.2)` for varied but controlled entrances.
- Use subtle camera pushes, panel slides, line traces, and status pulses.
- Every multi-scene transition uses a visible wipe, scanline, or panel cover; no jump cuts.

## What NOT To Do

- Do not use neon hacker visuals, fake terminal overload, or generic purple-blue SaaS gradients.
- Do not make the mythology the main visual language.
- Do not use loud glitch effects unless a single moment needs to imply noisy scanner output.
- Do not invent a new brand palette outside the Heimdall Oatmeal colors.
```
